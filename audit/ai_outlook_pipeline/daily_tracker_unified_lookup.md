# Daily Outlook Tracker & Unified Evidence Lookup

Date: 2026-09-18

## Daily AI Outlook Tracker (Section 19)

### Current Daily Outlook Mechanism

**Primary**: outlook.py via cron (09:30 and 19:00 IST, weekdays)

**Flow**:
1. outlook.py main() iterates INDEX_SYMBOLS (NIFTY, BANKNIFTY, FINNIFTY, SENSEX)
2. For each symbol: refresh_ai_outlook(conn, symbol)
3. refresh_ai_outlook() assembles data from indicators, regime, vix, price_1m
4. Calls AIOutlookEngine.generate(symbol, data, use_llm=True) → LLM
5. Stores in ai_outlooks table
6. Also generates static HTML page: market/nifty-outlook-<date>.html

### What "today's outlook" Means

| Time | Source | Notes |
|------|--------|-------|
| 09:30 IST | outlook.py (LLM) | Morning outlook |
| Every minute | data_fetcher_db.py (template) | Updates ai_outlooks with rule-based |
| 19:00 IST | outlook.py (LLM) | Evening outlook |
| Market closed | data_fetcher_db.py (template) | Reuses/cache latest |

### Daily Tracker Records

**Table**: market_outcomes (206 rows — daily outlooks for 4 indices)
- NIFTY: 67 days (2026-06-18 to 2026-09-18)
- BANKNIFTY: 67 days
- SENSEX: 67 days
- FINNIFTY: 5 days (started 2026-09-14)

### Static HTML Pages

**Pattern**: market/nifty-outlook-<date>.html
**Generated by**: daily_page.py (morning and close modes)

**Note**: daily_page.py uses outlook data to build HTML pages. It reads from market_outcomes table.

### Missing: 5-Minute Daily Tracker

There is NO 5-minute daily tracker. If the 5m pipeline worked, each day would have:
- ~78 5-minute outlooks per symbol (market hours = 7.5 hours = 15 candles/hour × 4+ hours)
- 4 symbols × 78 = ~312 daily 5-minute outlooks
- Currently: 0

## Unified Evidence Lookup (Section 20)

### Evidence Sources by Pipeline

| Source | Table | Status | Contains |
|--------|-------|--------|----------|
| 5m pipeline | market_evidence_5m | EMPTY | trend, momentum, structure, volatility, options, confirmation, conflict |
| Research | research_*.json | POPULATED (outcome tracking) | Various research data |
| Evidence JSON | ai_outlooks_* (JSON fields) | MISSING (legacy has no JSON) | N/A |

### Evidence Fields in ai_outlooks

**Legacy ai_outlooks**: The outlook is a flat JSON string with fields like:
- market_summary, market_regime, directional_bias, confidence, evidence_strength, volatility_classification, market_structure, etc.
- NO structured evidence breakdown (trend, momentum, etc. as separate fields)

**5m schema**: Has evidence_json, watch_levels_json, confirmation_json, invalidation_json, risk_json, material_changes_json
- All designed for structured evidence but NEVER POPULATED because generator never runs

### How Evidence Is Used

1. **Static HTML generation**: daily_page.py reads outlook JSON and renders HTML
2. **Index pages**: /api/<symbol> returns ai_outlook narrative
3. **Today page**: Renders regime, confidence, bias from ai_outlook
4. **Journal**: May reference ai_outlook for trade comparison

## Snapshot/Signal/Evidence Unified Lookup (Section 21)

### Current Lookup Patterns

**For AI Outlook** (via /api/ai-outlook/<symbol>):
1. Try ai_outlooks_5m → if empty, fall back to ai_outlooks
2. Parse JSON fields
3. Return current, previous, timeline, change

**For Market Snapshot** (via /api/<symbol>):
1. Read from market_regime (latest)
2. Read from indicators (latest)
3. Read from price_1m (latest)
4. Read from vix_data (latest)
5. Read from price_5m (latest 5m candle)
6. Read from options data (if available)

**For Evidence** (via /api/outlook/5m/latest/<symbol>):
1. Call outlook_change_detector.evaluate()
2. Reads market_regime, indicators, vix, price_1m
3. Returns current_state with regime, trend, confidence, vix, rsi, adx

### Cross-Referencing

| What | Where to Look | Table |
|------|--------------|-------|
| AI outlook (latest) | /api/ai-outlook/<symbol> | ai_outlooks or ai_outlooks_5m |
| AI outlook (daily) | /api/market-outlook?symbol=X | market_outcomes |
| Current regime | /api/<symbol> | market_regime |
| Current indicators | /api/<symbol> | indicators |
| 5m snapshot | /api/outlook/5m/snapshot/<symbol> | market_snapshots_5m (EMPTY) |
| Evidence | /api/outlook/5m/latest/<symbol> | Computed on fly from regime/indicators/vix/price |
| AI call log | research_ai_call_log | EMPTY |
| Outcome tracking | research_outcome_tracking | POPULATED |

### Unified View — What a User Sees

A user checking "What does AI think about NIFTY?" today:
1. Visits /today → sees AI outlook from ai_outlooks (template-based, not LLM)
2. Visits /indices/nifty.html → sees ai_outlook narrative from ai_outlooks
3. Visits /api/ai-outlook/NIFTY → gets structured data from ai_outlooks fallback

**All sources trace back to the same ai_outlooks table.** There is no independent verification because the 5m pipeline is broken.
