## 2. Findings

### A. Repository & deployment hygiene

**A1 (High) — Production tree is far ahead of git.** `git status`: 90 `M`, 1 `MM` (partially staged), 182 `??`, 2 `D`. `git diff --stat HEAD` = **93 files changed, +5790 / −8958**. Uncommitted core production changes include:
- `app/api/app.py` — new `/api/<symbol>/intraday` endpoint (~line 243) + docstring edits.
- `app/decision/view.py` — staged "DISPLAY FALLBACK owner-approved 2026-10-07" plus unstaged intrabar wording.
- `app/live/engine.py` — intrabar entry, plain variant.

Risk: no reviewable/revertable history for live behavior. *Recommend:* commit in logical, reviewed batches; never leave live logic uncommitted for weeks.

**A2 (Medium) — 149 tracked backup/junk files.** `git ls-files | grep -cE '\.(pre-|frozen-|backup_)'` = 149 (incl. 83 under `frontend/`). These are timestamped `.pre-*`, `.frozen-*`, `.backup_*` copies. They bloat the tree, appear in `ls`, and are only excluded from frontend tests by naming convention. *Recommend:* move to an out-of-tree backup location; add ignore patterns; purge from index.

**A3 (Medium) — 30 rotated log files tracked.** `logs/*.log.1`, `*.gz` are committed even though `.gitignore` only matched `logs/*.log`. *Fixed:* pattern extended (see §3).

**A4 (Medium) — Runtime state tracked.** `data/tg_state.json` and `data/tg_alerts_archive.jsonl` are git-tracked (they change every alert). This makes the working tree permanently dirty and risks losing/committing transient state. *Recommend:* untrack; add to `.gitignore`.

**A5 (Low) — Tooling friction.** Working dir `/opt/tradingai` is `dr-xr-xr-x`; `.pytest_cache` can't be written (pytest warns on every run). In-place edits require `chmod u+w`; root-level backups can't be created in-tree.

**A6 (Info) — Orphaned economics UI.** `frontend/fixed-loss-calc.js` / `.css` were removed 2026-10-07 (renamed `.remove-20261007`) and `fixed-loss-options.html` rebuilt as a static "Strategy Builder" with no external JS/CSS and no `/api` calls. The `/api/economics/calculate` endpoint (blueprint `app/api/e2_economics.py`) still exists and is tested, but now has **no frontend consumer**.

**B4 (Info) — Process/HTTP surface is sane.** No `shell=True`, no `eval`/`exec`, `subprocess` calls use fixed argument lists. `app.run(...)` is **not** in debug mode. nginx serves `.pre-*`/`.frozen-*`/`.backup_*` as 410, sets security headers, uses Cloudflare real-IP, and applies rate limiting.

### E. Learning pipeline

**E1 (Medium) — Decay is in-sample/circular.** `scripts/veto_score.py` decides decay from the same window it scores, and its gate `accuracy < floor OR net_r < floor` can **suppress net-R-beneficial rules**. Observed: `FALLING`-VIX rules were decayed *wrong* despite positive `net_r`. *Recommend:* separate hold-out/out-of-sample evaluation; don't decay on accuracy alone when net-R is positive.

**E2 (Medium) — Stale veto rows never removed.** `scripts/veto_paper_book.py` only does `INSERT OR REPLACE` (PK `(session_date, instrument_id, variant)`); rows that are no longer member trades persist forever. *Recommend:* delete rows not in the current membership set.

**E3 (Low) — Calendar vs session days.** `recent_sessions` (21) is compared against calendar-day deltas, not trading sessions, so the effective window drifts across weekends/holidays.

**E4 (Info) — Wiring verified.** `vix_dir` is derived from the OPEN of the first INDIA_VIX 5-min candle at/after entry vs prior VIX close (±0.25% → RISING/FALLING/FLAT) — live-knowable. `mistake_guard.py` reads `/api/decision/india_vix` `change_pct`; the live guard uses the **plain**-variant memory. `INDIA_VIX` is correctly excluded from config `instruments` (older analysis that included it as a pseudo-trade was confounded).

### F. Application / API

**F1 (Medium) — No auth on endpoints.** 29 routes in `app/api/app.py` (+ `e2_economics` blueprint) are unauthenticated; protection depends entirely on nginx rate-limiting + Cloudflare. Any origin reaching `127.0.0.1:8000` bypasses that. *Recommend:* bind-only-localhost (done) and consider IP allow-list; avoid exposing write endpoints (`/claim`, backtest POSTs) broadly.

**F2 (Info) — `/api/<symbol>/intraday`** is a new, uncommitted endpoint (A1).

**F3 (Info) — Stale test path** `/opt/tradingai_new` in `test_phase16.py` (see C2).

### G. Documentation drift

**G1 (Medium)** — `ARCHITECTURE.md` describes a scenario-based pipeline that no longer matches the live CPR-trigger path.
**G2 (Low)** — `start_api.sh` uses `--threads 2` while systemd runs `--threads 4`.
