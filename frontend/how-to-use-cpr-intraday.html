How to Use CPR for Intraday Trading

The Central Pivot Range gives intraday traders a fixed daily map: three central references (BC, Pivot, TC) plus S1/S2 and R1/R2 reaction levels. Below is a disciplined routine for reading that map on NIFTY and BANKNIFTY — the same routine the TradingAI model follows automatically each session.

Educational routine only — describes analytical references, not personalised investment advice. Options involve substantial risk; see the Disclaimer.

1. Build the morning map (before 09:15)

  1. Note TC, Pivot, BC and the width type (narrow/normal/wide) — see narrow vs wide CPR.
  2. Mark S1/S2 below and R1/R2 above, plus the previous day high/low.
  3. Decide in advance which closes would constitute evidence (e.g. a 5-minute close above TC) rather than improvising mid-session.

2. Assess the gap at 09:15

  • Gap up into/above resistance: prior supply overhead; upside needs acceptance above the level, not just a wick.
  • Gap down into/below support: mirror logic on the downside.
  • Flat open inside CPR: patience — the zone edges become the first decision points.

3. Wait for finished-candle evidence

Intraday CPR practice commonly requires completed 5-minute candles: touches and wicks are information, closes are evidence. The classification this site runs formalises that — reference observation only at the next open after a qualifying close, never intrabar. Typical trigger families: touches of S2/S1/PDL or closes above TC (bullish side); touches of R2/R1/PDH or closes below BC (bearish side). Exact rules: methodology.

4. Note the reference bounds first

Every CPR setup has a natural failure line — commonly a 5-minute close back through the level that triggered it. Predefining that line (and sizing so its breach is affordable) is what separates a routine from a guess. The 0.5% / 2% reference bounds with a 15:20 session reference close are one such fixed scheme, evaluated transparently on the backtest page.

5. Common mistakes

  • Trading wick touches as if they were closes.
  • Treating a virgin test and a retest as equal-quality events.
  • Ignoring width context — demanding breakouts on wide rotation days and ranges on narrow trending days.
  • Skipping the journal: log classification level, reference-bound notes and the session outcome daily (the paper ledger shows this discipline applied).
