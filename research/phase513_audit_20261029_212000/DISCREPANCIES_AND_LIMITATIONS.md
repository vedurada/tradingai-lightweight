# Phase 5.13 — Discrepancies and Limitations

## Material Discrepancy: TRADE_LEDGER.csv

`TRADE_LEDGER.csv` contains **974 rows** instead of the reported 729. The CSV has 245 extra rows. These are distinct trades (no duplicate keys) generated by a different code path in the first backtest script (phase512_backtest.py), which processed candle-by-candle and may have generated duplicate or spurious signals.

**Impact:** CSV-derived monthly performance and any CSV-based analysis are unreliable. The JSON files (729 trades) are the correct source.

**Resolution:** Use JSON files (TRADE_LEDGER_NIFTY.json, TRADE_LEDGER_BANKNIFTY.json) as the authoritative trade ledger.

## Other Discrepancies

1. **MONTHLY_PERFORMANCE.csv** was based on 974 CSV rows (wrong). Correct monthly performance recomputed from JSON (see PHASE513_REPORT.md).
2. **INSTRUMENT_COMPARISON.csv** was based on 974 CSV rows (wrong). Correct values recomputed.

## Limitations

1. Only 3.5 months of data (Jul 6 - Oct 29, 2026)
2. INDIA_VIX data starts Jul 29 (23 days later)
3. One session with missing candles (Oct 15)
4. No transaction cost data (costs estimated at 0.5 pts/trade)
5. No market regime classification
6. No volume analysis
7. Top 10 winners contribute 15.3% (moderate concentration)
8. BANKNIFTY contributes 72.5% of total points (concentration risk)
9. One-candle-later entry degrades performance significantly (S2)
10. Monthly WR varies 67-78% (instability)
